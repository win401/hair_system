# 미용사·사용자 확보 전략

## 1. 기본 전략

네이버를 대체하는 미용실 검색·예약 플랫폼으로 출발하지 않는다. 네이버는 계속 검색, 리뷰, 예약, 결제를 담당하고 우리 서비스는 스타일 결정과 디자이너 매칭을 담당한다.

| 고객 여정 | 담당 서비스 |
|---|---|
| 미용실과 후기 검색 | 네이버 플레이스 |
| 내 얼굴에 스타일 시뮬레이션 | 우리 서비스 |
| 현실적인 시술 가능성 검토 | 우리 서비스와 디자이너 |
| 해당 스타일 전문 디자이너 매칭 | 우리 서비스 |
| 일정 선택, 예약, 결제 | 네이버 예약 |
| 상담 내용 및 실제 결과 축적 | 우리 서비스 |

## 2. 공급자 확보

### 미용사의 도입 장벽

- 이미 네이버 예약을 사용하고 있다.
- 새로운 플랫폼의 계정과 예약을 관리하고 싶지 않다.
- 신규 플랫폼이 실제 고객을 가져올지 믿기 어렵다.
- 포트폴리오를 다시 등록하는 작업이 번거롭다.

따라서 초기 제안은 입점이 아니라 `개인용 AI 상담 링크 무료 제작`이어야 한다.

### 디자이너용 AI 상담 링크

```text
고객이 전용 링크 접속
→ 셀카와 원하는 스타일 입력
→ 디자이너의 실제 포트폴리오 기반 체험
→ 상담 카드 생성
→ 디자이너가 실현 가능성 검토
→ 기존 네이버 예약 페이지로 이동
```

### 초기 모집 방법

1. 미용·이용업에 종사하는 사촌, 이모, 이모부를 각각 인터뷰한다.
2. 이들 중 실제 테스트가 가능한 2~3명을 첫 현장 파트너로 정한다.
3. 포트폴리오와 고객 사진 사용 조건, 전문 분야, 상담 과정을 확인한다.
4. 대표 스타일 3~5개와 체험 링크를 대표자 1인이 직접 등록한다.
5. 가족 현장에서 20~30명의 고객에게 수동 파일럿을 진행한다.
6. 초기 문제를 수정한 뒤 소개를 통해 외부 디자이너 5명을 모집한다.
7. 관계가 없는 외부 디자이너에게도 같은 가치가 성립하는지 확인한다.
8. 전용 링크, QR, 인스타 게시물 초안을 제공하고 매주 성과를 리포트한다.

### 미용사에게 제공할 기능

- 개인 브랜딩 페이지
- 전문 스타일 체험 페이지
- 상담 카드 수신
- AI 이미지와 콘텐츠 생성
- 네이버 예약 연결
- 신규 고객 유입 통계
- 매장용 QR

## 3. 사용자 확보

사용자는 새로운 미용실 검색 앱 때문에 가입하지 않는다. 가입 전에 즉각적인 효용을 제공해야 한다.

### 첫 진입 상품

> 사진 한 장으로 현재 모발에서 시도할 수 있는 스타일 3개 확인하기

결과는 다음 세 가지 방식으로 제안한다.

- 가장 안전한 변화
- 인상이 가장 크게 달라지는 변화
- 현재 모발에서 가장 구현하기 쉬운 변화

스타일 이미지만 보여주지 않고 예상 시술 조합, 소요 시간 범위, 손질 난이도, 전문 디자이너를 함께 제공한다.

### 주요 유입 채널

#### 디자이너 보유 채널

- 인스타그램 프로필과 스토리
- 기존 고객 카카오톡
- 매장 거울과 대기석 QR
- 명함과 재방문 카드

#### 네이버 검색 콘텐츠

- 둥근 얼굴 중단발 레이어드컷
- 숱 적은 여자 단발
- 긴 얼굴 앞머리 추천
- 남자 곱슬 리프컷
- 탈색 없이 가능한 염색

모든 콘텐츠는 `내 얼굴로 체험하기 → 해당 스타일 전문 디자이너 → 네이버 예약`으로 연결한다.

#### 실제 결과 콘텐츠

AI 결과와 실제 시술 결과를 나란히 보여주는 콘텐츠를 핵심 홍보 자산으로 사용한다. 광고 또는 협찬 콘텐츠에는 관련 표시 의무를 준수한다.

#### 지인 협력 채널

투탁핀셔님이 콘텐츠 또는 홍보에 참여할 수 있다면 초기 인지도를 만드는 강한 채널이 될 수 있다. 다만 제품 품질과 상담 흐름이 검증되기 전에 대규모 노출을 사용하면 오류 경험만 널리 퍼질 수 있다.

권장 순서:

1. 내부 및 가족 파일럿 완료
2. 외부 사용자 20명 이상의 결과 품질 확인
3. 개인정보 동의와 삭제 흐름 점검
4. 소규모 비공개 체험 또는 콘텐츠 촬영
5. 전용 링크로 방문, 생성, 상담, 예약 클릭을 측정
6. 결과가 좋을 때 정식 공개 콘텐츠 진행

투탁핀셔님의 역할은 단순 게시물 공유, 직접 체험 콘텐츠, 브랜드 사운드·영상 협업, 지인 네트워크 소개 등으로 나뉠 수 있으므로 부담과 보상, 초상 사용 범위를 사전에 합의한다.

## 4. 성장 루프

```text
디자이너가 실제 시술 사례 등록
        ↓
스타일 체험 페이지 자동 생성
        ↓
검색·SNS·QR에서 사용자 유입
        ↓
사용자가 자신의 얼굴로 체험
        ↓
상담 카드와 디자이너 매칭
        ↓
네이버 예약과 실제 시술
        ↓
실제 결과와 만족도 축적
        ↓
추천 정확도와 디자이너 노출 향상
```

## 5. 추천 인센티브

### 디자이너

- 초기 포트폴리오 페이지 무료 제작
- 첫 3개월 무료
- 콘텐츠 및 QR 제공
- 초기 지역·스타일 상단 노출
- 신규 방문이 확인되기 전까지 성과 수수료 없음

### 사용자

- 첫 결과 3개 무료
- 친구 공유 시 추가 생성권
- 시술 결과 등록 시 추가 체험권
- 제휴 디자이너 상담 또는 매장 부가 혜택

## 6. 수익모델

예약 수수료만으로는 초기 매출 규모가 작을 가능성이 높다. 반복적인 효용이 있는 B2B 구독을 중심으로 설계한다.

### 디자이너 프로 예시

- 월 59,000원
- 스타일 체험 페이지 확대
- 월 AI 생성량 확대
- 상담 관리
- 콘텐츠 생성
- 전환 통계
- 개인 브랜딩

### 매장 프로 예시

- 월 199,000~399,000원
- 여러 디자이너 관리
- 매장 공용 QR
- 캠페인과 고객 관리
- 디자이너별 전환 통계

가격은 인터뷰와 유료 전환 실험을 거쳐 확정한다.

## 7. 유의사항

- 네이버 플레이스와 디자이너 정보를 무단 수집해 데이터베이스를 만들지 않는다.
- 초기에는 공개 예약 API 연동을 전제하지 않고 디자이너가 등록한 네이버 예약 링크를 사용한다.
- 네이버 예약 이후 방문 여부는 상담 카드 코드, 쿠폰, 고객 확인 등으로 보완한다.
- 장기적으로 필요성이 입증되면 공식 연동 파트너십을 검토한다.
