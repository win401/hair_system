# AI 헤어스타일 시뮬레이션 서비스 기획 문서

이 폴더는 사용자가 원하는 헤어스타일을 자신의 얼굴로 미리 확인하고, 실제 시술이 가능한 디자이너와 연결되는 서비스의 초기 기획을 정리한다.

## 현재 제품 가설

> 고객이 원하는 헤어스타일을 자기 얼굴로 확인하고, 실제 구현 가능성을 상담한 뒤 기존 네이버 예약으로 자연스럽게 연결한다.

단순한 헤어 이미지 생성기가 아니라 `스타일 탐색 → 시뮬레이션 → 현실성 검토 → 디자이너 상담 → 네이버 예약 → 실제 시술 결과`를 잇는 의사결정 서비스가 목표다.

## 초기 전제

- 운영 형태: 대표자 1인이 제품 개발, 영업, 운영을 담당
- 초기 현장 파트너: 미용·이용업에 종사하는 사촌, 이모, 이모부
- 잠재 홍보 협력자: 지인인 투탁핀셔님(역할과 참여 범위는 미정)
- 대상 지역과 첫 카테고리: 가족 현장의 위치·전문 분야를 확인한 뒤 결정
- 초기 공급자: 가족 네트워크 2~3명으로 시작해 외부 디자이너 5~10명으로 확장
- 초기 채널: 모바일 웹, 인스타그램, 카카오톡, 네이버 블로그
- 예약 및 결제: 기존 네이버 예약 사용
- AI 방식: 외부 이미지 생성 API로 먼저 검증
- 앱, 실시간 AR, 자체 AI 모델은 검증 이후 검토

## 아직 결정하지 않은 사항

- 첫 타깃 상권
- 첫 스타일 카테고리
- 최종 브랜드명
- 생성형 AI 공급자
- 디자이너 과금 방식과 가격
- 예약 완료 여부를 확인하는 운영 방식
- 투탁핀셔님의 구체적인 협력 가능 범위
- 가족 종사자의 전문 분야, 근무 지역, 고객층과 네이버 예약 사용 여부
