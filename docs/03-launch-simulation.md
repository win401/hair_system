# 서비스 출시 실행계획

## 1. 실행 목표

1인 사업자가 5개월 안에 모바일 웹 베타를 출시하고, 6~9개월 동안 한 현장과 한 스타일 분야에서 예약 전환 가능성을 검증한다.

검증할 핵심 명제는 다음과 같다.

> AI 시뮬레이션과 상담 카드가 없을 때보다 디자이너에게 실제 신규 고객을 더 많이 보낼 수 있는가?

## 2. 1인 운영 구조

### 대표자

대표자 1인이 제품 결정, 개발, 영업, 고객 대응, AI 결과 검수와 데이터 분석을 담당한다. 동시에 많은 기능과 채널을 운영할 수 없으므로 자동화보다 먼저 범위를 줄인다.

권장 시간 배분:

| 업무 | 비중 |
|---|---:|
| 제품 개발·품질 개선 | 50% |
| 고객 및 AI 결과 운영 | 25% |
| 현장 인터뷰·파트너 관리 | 15% |
| 콘텐츠·마케팅 | 10% |

### 고정 직원이 아닌 협력 네트워크

- 사촌, 이모, 이모부: 업계 자문, 현장 인터뷰, 파일럿 장소, 초기 고객 접점 후보
- 투탁핀셔님: 제품 검증 이후 콘텐츠·홍보 협력 가능성이 있는 지인
- 외부 전문가: 개인정보·법률처럼 대표자가 단독 판단하면 위험한 영역에 한해 건별 자문

이들을 고정 팀원이나 확정된 홍보 채널로 계산하지 않는다. 참여 의사, 가능한 시간, 보상, 사진과 콘텐츠 사용 범위를 별도로 합의한다.

## 3. 20주 실행 로드맵

### 1~2주차: 문제 검증

가족 종사자 3명과 잠재 사용자 10명을 먼저 인터뷰한다.

완료 기준:

- 사용자 5명 이상이 실제 셀카 업로드
- 사용자 3명 이상이 결과 저장 또는 전달
- 가족 종사자 중 2명 이상이 파일럿 참여 의사 표시
- 포트폴리오와 고객 사진의 사용 조건 확인
- 가족과 관계없는 디자이너 2명에게 별도 인터뷰

### 3~4주차: 컨시어지 MVP

웹서비스 없이 신청 폼과 수동 운영으로 전체 여정을 테스트한다.

```text
셀카·설문 접수
→ 운영자가 AI 결과 3개 생성
→ 품질 검수
→ 디자이너가 현실성 확인
→ 상담 카드 전달
→ 네이버 예약 이동
```

목표:

- 신청 20명
- 정상 결과 제공 15명
- 저장·공유 7명
- 상담 요청 3명
- 네이버 예약 이동 2명
- 실제 방문 1명 이상

### 5~10주차: 웹 MVP 개발

사용자 기능:

- 비회원 또는 최소 정보 인증
- 셀카 업로드 및 촬영 안내
- 모발 상태 설문
- 스타일 선택
- AI 결과 생성과 비교
- 결과 저장·공유
- 상담 카드 생성
- 디자이너 조회
- 네이버 예약 이동
- 사진 삭제

디자이너 기능은 별도 관리 시스템 대신 전용 링크와 간단한 응답 화면으로 시작한다.

- 프로필과 예약 링크
- 포트폴리오 및 전문 스타일
- 상담 카드 확인
- 가능·조건부 가능·어려움 응답
- 주간 요약 통계

운영자 기능은 스프레드시트와 최소 관리 화면을 병행한다.

- 생성 결과 검수
- 신고·삭제
- 디자이너 승인
- 상담 상태 관리
- AI 비용 및 실패율 확인

제외 범위:

- 앱스토어 앱
- 실시간 AR
- 3D 두상
- 자체 생성 모델
- 자체 예약·결제
- 실시간 채팅
- 자동 추천 랭킹
- 복잡한 디자이너 CRM

### 11~14주차: 가족 네트워크 비공개 파일럿

- 가족 종사자 중 참여 가능한 2~3명 선정
- 1명당 사용 허락이 확인된 포트폴리오 10장 내외 확보
- 1명당 대표 스타일 3개 제작
- 전용 링크와 QR 배포
- 고객 20~30명에게 제한적으로 체험 제공
- 상담과 예약 과정을 운영자가 직접 지원
- 매주 현장 인터뷰와 문제 기록

### 15~20주차: 외부 디자이너 파일럿과 제한 공개

- 가족 또는 지인 소개를 통해 외부 디자이너 5명 모집
- 가족 관계가 없는 일반 사용자 30명 이상 테스트
- 투탁핀셔님과의 협력이 가능하면 소규모 비공개 체험 콘텐츠부터 검증
- 성과가 확인된 후에만 공개 홍보 진행

공개 조건:

- AI 결과 운영 승인율 70% 이상
- 결과 저장·공유율 25% 이상
- 상담 또는 예약 클릭률 8% 이상
- 얼굴이 크게 변하는 오류 5% 미만
- 디자이너 주간 사용률 50% 이상
- 개인정보 삭제 요청 처리 체계 확보

## 4. 파일럿 퍼널 가정

가족 현장 3곳 또는 종사자 3명이 한 달간 서비스 링크를 제한적으로 배포하는 상황을 가정한다.

| 단계 | 가정 인원 | 전 단계 대비 |
|---|---:|---:|
| QR·메시지 노출 | 300 | - |
| 체험 페이지 방문 | 90 | 30% |
| 사진 업로드 시작 | 45 | 50% |
| 정상 결과 생성 | 34 | 76% |
| 결과 저장·공유 | 10 | 29% |
| 디자이너 프로필 확인 | 7 | 21% |
| 네이버 예약 클릭 | 4 | 12% |
| 실제 예약 | 2 | 6% |
| 실제 방문 | 1~2 | 3~6% |

이 숫자는 매출 예측이 아니라 어느 단계에서 사용자가 이탈하는지 판단하기 위한 실험 가설이다.

## 5. 마케팅 배분

| 채널 | 초기 비중 | 목적 |
|---|---:|---|
| 가족 현장·디자이너 보유 고객 | 60% | 비용 없이 신뢰 기반 유입 확보 |
| 네이버 검색 콘텐츠 | 20% | 구체적인 헤어 고민 검색 유입 |
| 지인 콘텐츠·UGC | 15% | AI 결과와 실제 시술 비교 증명 |
| 유료 광고 | 5% | 제품 검증 이후 메시지 실험 |

광고는 앱 설치가 아니라 즉시 셀카를 업로드할 수 있는 체험 페이지로 연결한다.

## 6. 예상 비용

### 1인 사업자가 직접 개발하는 경우: 5개월, 본인 인건비·생활비 제외

| 항목 | 예상 범위 |
|---|---:|
| AI·클라우드·저장소 | 50만~250만원 |
| 디자인·브랜딩 | 0~100만원 |
| 법률·개인정보 검토 | 100만~300만원 |
| 제휴 영업·촬영·교통 | 50만~150만원 |
| 콘텐츠 제작·협력 | 50만~300만원 |
| 광고 테스트 | 0~100만원 |
| 기타 운영비 | 50만~150만원 |
| 합계 | 약 300만~1,350만원 |

웹 MVP를 외주 개발하면 범위와 품질에 따라 약 2,000만~5,000만원 이상이 추가될 수 있다. 1인 사업의 장점을 유지하려면 핵심 개발은 직접 하고, 개인정보 검토와 디자인처럼 전문성이 필요한 작업만 건별 외주를 사용하는 편이 적합하다. 실시간 AR이나 자체 생성 모델은 별도 규모의 투자가 필요하다.

위 금액은 견적이 아니라 초기 예산 수립용 가정이며, 공급자 견적과 실제 생성 테스트 후 다시 산정해야 한다.

## 7. 운영 장면 예시

1. 디자이너가 사용 가능한 포트폴리오 10장 내외를 전달한다.
2. 대표자가 사용 허락을 확인하고 대표 스타일 3개를 등록한다.
3. 체험 페이지와 인스타그램 콘텐츠를 만든다.
4. 고객이 링크를 통해 셀카와 원하는 스타일을 제출한다.
5. AI 결과를 생성하고 운영자가 오류를 검수한다.
6. 디자이너가 현재 길이와 모발 상태를 보고 가능 여부를 응답한다.
7. 고객이 네이버에서 예약한다.
8. 실제 방문 시 상담 카드를 사용한다.
9. 고객 동의 후 AI 결과와 실제 시술 결과를 비교한다.
10. 해당 사례를 새로운 검색 콘텐츠와 체험 템플릿으로 활용한다.

## 8. 핵심 지표

### 사용자

- 방문 대비 사진 업로드율
- 생성 성공률
- 결과 저장·공유율
- 상담 카드 생성률
- 네이버 예약 클릭률
- 실제 방문율
- 결과 만족도

### 디자이너

- 주간 활성 디자이너 비율
- 월평균 상담 카드 수
- 디자이너당 신규 방문 고객 수
- 상담 응답 시간
- 유료 전환율
- 월 이탈률

### 기술·운영

- 건당 생성 비용
- 평균 생성 시간
- 재생성률
- 운영자 검수 탈락률
- 개인정보 삭제 처리 시간
- 얼굴 또는 신체 특징 왜곡 발생률

## 9. 6~9개월차 확장 기준

- 외부 유료 디자이너 10명 이상
- 디자이너 월 이탈률 10% 이하
- 디자이너당 월 신규 고객 3명 이상
- 생성 결과 만족도 평균 4점 이상
- 생성 사용자 대비 실제 예약 전환율 3~5% 이상
- 실제 시술 결과 사례 30건 이상
- 신규 방문 한 건을 만드는 비용이 예상 수익보다 낮음

기준을 충족하면 인접 지역과 스타일 카테고리로 확장한다. 예약 전환율이 1% 미만이거나 디자이너가 신규 고객 효과를 체감하지 못하면 자체 AI 모델, 앱, 전국 확장을 보류하고 포지셔닝을 다시 검토한다.

## 10. 바로 실행할 작업

1. 사촌, 이모, 이모부의 전문 분야·지역·고객층·네이버 예약 사용 여부 정리
2. 세 사람을 각각 따로 인터뷰해 현장 문제와 지불 의사 확인
3. 첫 파일럿 현장과 스타일 카테고리 결정
4. 사용자 인터뷰 질문지 작성
5. 셀카 및 모발 설문 신청 폼 제작
6. AI 이미지 생성 공급자 2~3개 품질·가격 비교
7. 상담 카드 예시 화면 제작
8. 개인정보 처리 흐름과 삭제 정책 초안 작성
9. 고객 20명을 대상으로 컨시어지 MVP 운영
10. 외부 디자이너 2명과 일반 사용자에게 교차검증
11. 투탁핀셔님에게 요청할 수 있는 협력 범위와 공개 시점 정리
